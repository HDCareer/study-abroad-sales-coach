# 安装与升级

当前版本：0.7.31-public.1。下载链接见[首页](../README.md)。公开包不含内部价表；组织内部使用者请在私有位置补充适用政策，勿上传到本仓库。

## 完整Skill环境

下载完整Skill ZIP，使用平台实际提供的导入入口；若需要目录，先解压，选择直接包含SKILL.md、references、scripts、assets的那层。不要只上传入口文件。不同平台读取能力不同，本版未逐一安装验证。

已有用户留存原资料后更新完整包；自有业务资料单独存放，避免被升级覆盖。更新后新开客户对话并检查版本，不将旧长对话中的承诺带入新客户。

## Gem或普通聊天的文本知识方式

下载Gem知识备用ZIP，**先在电脑上解压**。使用“粘贴到Gem指令框.txt”作为指引，上传00-core.md及8个场景MD。README和许可是安装说明，不必作为业务知识上传。普通聊天窗口按实际支持的文件方式提供解压后的文本；上传附件本身不证明规则已经完整读取，也不证明已永久安装。

本知识包不执行Python脚本。处理聊天表格或图片时应确认实际读到了什么，无法执行时输出文字/表格，不能声称生成或校验过HTML。

## 版本与读取检查

要求助手：报告当前版本，并从已读取资料说明日常客户稿的长度规则、具体服务怎样协商、未获回传能否宣称已确认。读不到哪份文件就明确说明。预期版本为0.7.31-public.1；不能仅凭回答了版本号认定安装成功。

再给一条不含机构报价的虚构询价，确认它不把示例金额当真价。首次真实使用由销售复核，保留未经修改的原稿。团队反馈方法见[试用说明](TEAM-TRIAL.md)。

## 本版管理报告检查

用不含真实信息的小批样例，检查首页、五环节、判断/表达两层、来源摘录、训练验收及末尾必须跟回入口。未提供机构预警时限时应显示待设，不自动使用默认数字。每次统计期和资料截止分别显示。

## 连续复盘与统一结果

完整Python执行环境可按references/review-results.md和references/longitudinal-review.md生成统一结果与跨周观察。先用合成材料检查：同一客户续接、重复上传不加数、培训执行与建议分开、期限到期停止使用。缺少机构期限配置时公开版拒绝写跨周档案。

## Daily管理

连续管理按references/daily-management.md填写cadence=daily、动作、覆盖和成熟期资料。有获准保留的上期统一结果才传--previous-results；首次省略。旧输入缺cadence仍按周兼容，week字段在Daily表示当日。不要把AI草稿当作已发送；任务状态须带入下次分析，工具不是后台任务库。
