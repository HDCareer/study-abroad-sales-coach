# 安装与升级

当前版本：0.7.22-public.1。下载链接见[首页](../README.md)。公开包不含内部价表；组织内部使用者请在私有位置补充适用政策，勿上传到本仓库。

## 完整Skill环境

下载完整Skill ZIP，使用平台实际提供的导入入口；若需要目录，先解压，选择直接包含SKILL.md、references、scripts、assets的那层。不要只上传入口文件。不同平台读取能力不同，本版未逐一安装验证。

已有用户留存原资料后更新完整包；自有业务资料单独存放，避免被升级覆盖。更新后新开客户对话并检查版本，不将旧长对话中的承诺带入新客户。

## Gem或普通聊天的文本知识方式

下载Gem知识备用ZIP，**先在电脑上解压**。使用“粘贴到Gem指令框.txt”作为指引，上传00-core.md及8个场景MD。README和许可是安装说明，不必作为业务知识上传。普通聊天窗口按实际支持的文件方式提供解压后的文本；上传附件本身不证明规则已经完整读取，也不证明已永久安装。

本知识包不执行Python脚本。处理聊天表格或图片时应确认实际读到了什么，无法执行时输出文字/表格，不能声称生成或校验过HTML。
