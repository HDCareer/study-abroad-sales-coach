# 试听、低配合与持续跟进

依据：逐字稿关于下一动作、自学检查、课堂练习点评，话术库03—04、10—17、34—40、44—48，试听与业务协作方法。持续带单与明确拒收联系的边界以入口为准；业务条件读[业务事实](business-facts.md)。

## 试听是有目的的验证

试听适合解决具体老师、讲解方式或当前任务能否获得帮助的疑问，不是每个客户必经步骤，不是回避正式价格，也不是让客户先付一点再被动得知大包费用。客户直接因试听广告来，先准确承接他看到的实际条件；小需求如果符合真实产品规则，可以只处理小需求。

大致需求与正式投入已说明、主要疑虑是体验时，解释本次验证什么。客户因首节优惠而来时，也可把优惠用于实际任务的第一步，说明真实教学收获与后续费用；不把首节仅当宣传演示，不要求每位客户必须先试老师。客户要试听时，按[试听购买与退款政策](business-facts.md#试听购买与退款政策)核实试听与正式课的购买数量和费用关系；按本机构已确认的另购、包含或抵扣政策处理。推荐与客户接受分开，不能默认免费、抵扣或强制捆绑。课前沟通不是教学课；如果本机构已确认付费试听提供实际教学，可在该范围内先推进任务；授课先后不决定它是否包含在原购买数量里。教学性质相同不等于后续仍享首节优惠，计时与费用按业务事实核算。客户问试听后是否仍按试听价、换老师能否重新享受优惠时，直接按本案例已确认的政策回答，政策未知就向销售核实这一个条件；不推断首次优惠可无限重复。

客户未接受全程预算时，按[报价后的价值说服](closing.md#报价反馈用来定位阻碍)回应其顾虑，再提供有独立教学价值、客户愿意承担的首节目标；不用接受大课包作为购买首节的前提。明确本节推进什么、课后自己做什么、后续按什么结果决定，真实正式费用提前说明。若客户仍要求用首节费用解决整个任务，就先说明这两种范围的差异；不以低价暗示全程已覆盖，也不预定以后必续费。期限紧时把自做与反馈时间纳入可行性判断。

体验入口有两种不同用途：尚未开始，可建议先定方向、理清起步步骤，学生课后尝试；已有初稿，可将首节用于检查和局部优化。后者以客户能够先完成初稿为条件，不让完全不会起步的人无支持地自己做完再来。试前讲清与卡点相关的观察标准，如讲完能否自己说明下一步并尝试；同时验证教学适配和推进任务。具体产出数量、计时与安排以真实信息为准；后续是否继续看实际完成内容和剩余问题，不只看主观满意，也不保证首节必定完成。

如果用独立练习后的反馈帮助客户判断是否续课，这次反馈就是体验方案的一部分：推荐时说明谁在何时看什么、包含在哪里及是否另付费。课堂内的独立尝试按首课范围安排；课后已讲内容的答疑按本机构确认的范围、时长和费用说明；新材料的独立分析、整份检查或额外教学不能自动纳入免费答疑。具体回看是否包含尚未明确，就在客户决定购买前取得范围和费用，并向客户说清这项待定条件；同时保留已有依据的体验目标，不把推荐退成只说“我去确认”。客户只需自行尝试、尚未提出教师回看时，不额外添加付费检查环节。已知条件直接沿用，不每次把全部售后条款重讲一遍。

当客户用“别人免费”否定收费时，先回答真实费用，再用已确认的首节教学属性说明这笔钱用于什么、为何适合他的当下目标。验证老师与推进学习可以并行；不要只说付费是为了看看老师好不好，也不要用“拿一道题找卡点”替代所有教学价值。老师及本案安排已有信息就用，未有则用教学建议表达，不假造已定教案。不能推定免费课只有介绍、收费必然优质；如果双方服务经核实相当，正面处理真实价格条件，不重复强调付费。

根据客户共识选择推进：只问有没有试听，先答真实政策；向本客户推荐优惠入口时，按[适用条件](business-facts.md#怎样使用已知与未知事实)处理，费用和教学用途得到认可后再落实上课安排。客户明确只接受免费时，判断真实权限/其他路径，不能继续用低价试听掩盖后续预算。先沿用已明确的数量关系与现行退款政策；确实缺失的时长或补差价算法才内部确认，影响当前购买决定的待定费用也要告诉客户。另购建议要说清增加的数量与费用，客户未接受不作已成交处理。

客户已明确选择单独首节时，简洁确认其选择，重申这节的实际目标、需要说明的收费退款条件，接下一项排课信息即可。用“这节先理清起步步骤，课后你按这个思路试着做，看看能不能自己往下推进”自然表达范围；需要教师回看时沿用前面说清的反馈安排。无完整交付误解时，不主动堆叠“不承诺完成整份、不保证结果”等免责声明，也不重讲刚已认可的全部价值。客户明确追问整份是否能完成时，仍须准确答复。

试听前给销售一份精简的内部交代：当前任务与范围、客户具体卡点、目标/期限、语言或节奏要求、允许使用的材料、已经告知的费用与承诺、本次需要观察的变化。利用现有信息，不让客户再填完整问卷；安排必须等实际师资和时间确认。不要为一般异议都先建大群、启动完整师资匹配。

试听结束后以实际反馈判断：

- 已有学生反馈先用，不机械问“感觉怎么样”。没有具体反馈时，在适合联系的节点让学生自然说收获或还卡在哪里；销售刚发过收尾或问题且未回复，先准备老师反馈，不为补齐回访立即再问。发送时机遵循下方沉默处理，不把回访变成考试。
- 区分老师讲得清楚、学生当时听懂、学生能独立做和剩余目标；一次体验不能证明整学期或保分结果。学生喜欢老师但仍嫌贵时，局部体验作为有效性依据，按[报价反馈](closing.md#报价反馈用来定位阻碍)补后续投入的购买理由；不能由满意直接推成“价值已认可，只差预算”。
- 结合老师实际反馈说明本次解决什么、后续仍需什么。老师未反馈就是未知，不能代拟“老师说你基础太差”。
- 学生明确说快、没听懂、口音影响理解时，先承接这次体验没帮他跟上，再定位最关键问题并要求具体调整；不能先为老师辩护或用优惠转移。原因已知不再盘问是否老师/价格/时间。
- 家长满意不能覆盖学生负面体验；双方关注点不同先对齐。调整或换师要实际确认，不能承诺已经换好或必定有效。
- 真实反馈支持原定路径后，回到已知剩余需要、原方案和费用。没有新需求不临时从10/14小时推到20小时；确需调整说明新增事实和用途。

## 简短回复、缺资料与交流负担

“嗯、没有、no”先看它在回答什么；一句否定可能仅是没有课件，不是拒绝辅导。不能凭回复短判低质客户或强行推进付款。

如果连续几轮都在收集信息，先检查销售有没有提供足够价值。能用已有事实给判断或解释就先给，减少下一步负担；只有会改变动作的一项才轻问。上次问题多且未获回答时，在合适跟进节点先给已有信息支持的判断，再保留一个最影响动作的回应入口，例如“现在更卡在思路，还是已经动手但结果不对？”；选项须贴合任务，并留出其他可能。已答内容不重问，客户不便提供的资料不换名追索；若下一步应由销售内部完成，就明确内部动作，不硬加客户问题。客户不能解释术语时换生活化或任务化问法，不让他完成专业诊断才能获得帮助。

对方已说材料没有或不能分享，停止围绕同一资料追索。已知“看懂却不会开始”足以给有限学习路径，不能为了拿材料反复绕圈。之后把精确范围交给能查看实际任务的导师确认。

## 商量与下次联系

客户说要和父母、伴侣或其他人商量时，销售必须弄清三件事，才能带着具体事情接续；已知就承接，不机械重复三连问。

1. **商量什么。** 本人是否已经认可、谁参与哪项决定，从前文继承。只差家长转钱、预算需要批准、家长还想判断是否补习或老师，所需说明不同。客户同轮议价并说要问家里、事项未知时，先接住，再自然问“这也不是一笔小钱，确实跟父母好好商量一下比较好。你主要是商量费用，还是跟他们确认要不要补习？”这一轮客户稿先到这里，答案会决定下一步；销售可内部准备，不把已讲过的费用范围、卖点、优惠核实和联系安排一起发过去。已知就直接接续，不要求每案重问。不要把商量一概当拖延，也不把父母限定为付款人。
2. **什么时候能有结果。** 询问或沿用预计商量后能决定的时间；“今晚聊”不等于“今晚一定决定”。客户说不准时，销售主动提出一个具体联系时点，请客户确认；到时可以先交流进展，不要求他届时必须作出购买决定。
3. **下次何时联系、接着处理什么。** 有预计结果时间，就在其后提出方便联系的具体日期和时刻；没有明确结果时间，也先提出进展沟通的具体时点。不能停在“明天下午、过两天、聊完再说”。相对日期须在当前对话中无歧义，跨地区时明确按哪一方当地时间。说明联系用途：看看家长还有什么问题、补清费用或落实已经认可的课程。客户答应后才是约定；只有销售单方提议，销售指引须保留“待客户确认”。收到结果后按它改变动作，不空问“考虑好了吗”。

确认主要商量费用后，让客户带着具体方案回去谈。已定数量和总价直接沿用；若仍只有课时范围，就依据现有评估提出具体数量、每节时长、原总价及分工，请客户认可，再按[真实申请](closing.md#人工介入与真实申请)争取该方案优惠。数量尚待认可时，本轮收在“先按这个方案争取优惠，可以吗”；客户答复后再接家庭预计结果与联系时间。三项衔接要逐步落实，不为了当轮补齐跟进信息而连续问三个决定；方案已经认可则可直接处理后两项。家庭仍在决定是否需要辅导时，先处理这个决定；不借优惠替他们选更大的课包。客户已给同方案可成交总价，直接处理条件，不重问本人意愿或家庭角色。

客户明确要今天等结果、尽快开始时，销售应主动提出可执行的具体进展回报时点，写清日期、时刻和当地时区，请客户确认。届时说清已确认事项、仍待哪项及其后续处理；回报时间不等于批准或上课时间，不承诺负责人何时一定批。已有约定直接用，客户不愿约时尊重其选择。不以重复“有结果就通知你”代替这个安排，也不在等待中连续发送空进度。

负责人认可的本案示范（学生已表示先买三小时、准备与父母商量；结尾采用负责人修改）：

> 好，那咱们就按先上三小时的方向来准备。你跟爸妈主要是商量这笔费用，还是他们也想了解一下老师和上课安排？
>
> 我可以把这次为什么建议先上三小时、老师具体怎么帮你，还有费用，整理成一段你方便发给他们的说明。这样爸妈也能看明白，这笔钱是用来解决什么问题的。
>
> 你大概什么时候能跟他们商量出结果呀？咱们约个你聊完后方便的时间，我再联系你。爸妈有什么想了解的，我帮你一起解释清楚；如果他们这边也觉得可以，咱们就直接定下来。早点跟老师约好课，你也能腾出更多时间来备战考试，从容过关。

这段先承接已表达的购买意愿，再问商量事项、提供转述帮助，最后把家庭反馈接回购买与约课。适用事实未变时保留已认可表达，不为润色改成抽象总结。三小时只属于本案，“从容过关”表达备考期待，不扩写为保证通过。此时尚未约成具体时间，必须接客户回复落实；“聊完后”不算已经完成跟进安排。

若客户接着说“今晚聊，应该明天有结果”，可接：“那我明天下午三点，按你当地时间，再联系你，听听爸妈怎么说，有需要解释的咱们一起说清楚。这个时间方便吗？”若客户说“还不知道什么时候能商量好”，可接：“那咱们先约明天下午三点，按你当地时间，我再联系你。到时候要是还没商量完，我们就先聊聊进展；爸妈有什么想了解的，我也好帮你解释。这个时间方便吗？”这是提议时点的示范，不是所有客户固定约明天三点，应结合现有沟通与作息信息选择。客户已说“明天下午三点找我”，直接承接日期、当地时区与待办，别再问何时联系。客户说该时点不方便就另约具体时间；明确不愿约时尊重其选择，内部记录尚未约成，不能把模糊时间记成完成；明确拒收联系时按入口停止。

提供转述材料可以同时进行，不能用“有顾虑再告诉我”替代以上衔接。销售负责真实联系；Skill只给安排与话术，不声称已设置提醒或后台自动跟进。

## 沉默的处理取决于当前节点

没有回复只是一项观察，不等于忙、没钱、不信任或没需求；此前问过服务或排期也不能排除价格顾虑。客户已明确嫌贵就保留这一阻力，不重新泛问沉默原因。先看最后一条实际已发消息、距离时间、客户约定、可用期限与本轮能提供的实质内容，再决定是否现在发送，最后才拟跟进话术。刚发过问题或收尾时，轻问也不能绕过等待判断。截图未说明间隔且没有其他即时联系依据，给销售有条件的接续建议，不默认立即追加，也不为此一律要求用户补时间。客户今天要决定时，可以按上节约有用途的进展回报；不另约空聊，也不把仍在等待内部确认说成已有新结果。没有自动时钟、提醒或发送能力，不能声称正在后台盯单。

| 状态 | 帮销售决定下一步 |
| --- | --- |
| 刚发完、仍处于正常阅读或考虑窗口 | 明确现在等待的理由，准备下一次有用的信息；不因几分钟沉默马上连催 |
| 加好友后从未回复 | 接续前端已知需求，用一条相关、低负担的信息说明能帮什么；后续换有价值的切口，不重复“在吗”或凭空下诊断 |
| 诊断后无回应 | 检查最后一条是否长、难回答、重复或没有价值；用已有信息给具体判断，将仍必要的未答问题缩为一个容易回应的下一步；不能把少问变成只讲判断、不留行动 |
| 报价后无回应 | 先补漏答费用或未解顾虑，优先带回真实方案、费用或师资结果；原因未知不排除价格，不自动降价或判流失 |
| 已明确接受条件并同意排课 | 直接落实真实可用安排，不重新问价格、老师、时间哪个有顾虑 |
| 已约考虑/问家长/自学后反馈 | 尊重约定，准备约定要讨论的内容并在相应节点接续；不提前反复催付，也不无限期放任 |
| 已经连续有实质跟进仍无回应 | 根据需求期限、既有约定与是否还有有效信息决定下一跟进或暂停；说明恢复触发条件，不机械再发一条 |

指引中指出当前等待什么、销售现在能准备什么，以及在何种实际反馈或约定节点恢复；没有新证据或新办法时，不能把改写同一句催问称为新策略，也不预设下午、晚上连续跟进。若尚无内部结果，可以用已有事实给一个具体判断；确实没有有用内容则说明内部准备与恢复节点，不硬凑客户消息。客户抱怨沟通麻烦时，先承接实际未推进的地方，直接回答本轮能回答的内容；未回的业务事项交给对应人员继续处理，不再补发多个空的等待承诺。已知信息足以补漏答、给有限判断或帮助比较时，不必等所有人工结果齐全；若既无结果又无有用建议，明确内部待办及恢复条件即可。跟进围绕未完成的问题或决策，给新价值不一定要发新材料：可以是更清楚的任务判断、修正后的真实安排、便于转述的方案或可执行的检查点。不要用“今天最后名额、考前肯定来不及”制造并不存在的紧迫性。

跟进时间是基于本客户提出的建议，不等于客户已接受的约定。明确日期时核对当地日期和时区；没有足够依据就用真实事件节点。行政有效线索/失联认定见业务事实，不把72小时行政条件做成所有客户的催促或放弃计时器。

客户要求“现在把材料发我”，就提供当前已有的任务目标、已确认方案/报价、真实证据和必要待确认项；没有新优惠，不说“优惠后的总价”。家长参与时整理便于转述的短说明，并按[商量与下次联系](#商量与下次联系)承接具体决定和时间，不把所有问家长都变成付款问题。

竞品方案只能辅助比较，不让客户替我们完成自身价值证明。已有价格异议时，先提供本方能解释的价值或条件；客户愿意分享才结合对方实际范围比较，不重复索要名称和截图。Follow-up应继续尚未完成的决定，带回明确新增结果或有用判断；跟进并非只能等待外部材料，也不是在客户说“再看看”后自动退出。

### 客户正在回复“考虑”时先处理已知阻力

“考虑”不自动变成已经约好的跟进，也不要求再问一次“价格还是老师”。如果刚才的真实阻力是首次付费风险、总预算或实际讲法，本轮围绕该项给一个尚未尝试、能帮助决定的建议：已知方案摘要、真实可用体验、授权咨询或具体接续节点。不要让“你先比较，我再核实”成为所有异议后的统一退出语。

语气可以温和而建议明确：“按你现在的目标，我建议先……”并说明原因。若上一轮已经说完、客户只是需要阅读或内部结果仍未回，不为表现强势追加同一论证；尊重已约时间，不把合理等待误判为放弃。

## 反复拒绝时换走法，不结束教练工作

先承认已说清的限制，再判断真实可行动方式。客户已认可价值且明确现实资金上限，就处理条件；仅销售讲过价格不证明客户认可，仍有必要性或效果顾虑时，按新反馈补实质论证，避免重复原说法。资料无法分享就不换名继续要；老师讲太快就不再只发履历。每轮给有依据的动作，必要时是内部核实或按约等待。明确附条件购买但权限未知时，按[成交规则](closing.md#人工介入与真实申请)准备真实申请，不把“AI不能批准”解释为必须回绝。

想自学时，依据实际目标和时间给一个可观察检查点，例如能否独立完成同类练习，而非看视频时觉得懂。安排应给后续调整留出空间，但不能编造学校题目或要求分享被禁止的材料。销售承担接续责任，不以“做不来再找我”结案。

确实没有当前可售方案时，不假装存在低价单课、分期或能满足全部要求；给销售核实真实例外、提供可行的非购买建议或围绕明确变化节点再联系的行动。客户明确拒收联系时按入口停止推销，不能把拒收回复当成持续销售许可。
